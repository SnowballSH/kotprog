# Snippets

This directory is a copy-paste library for contests.

- `src/Main.kt` stays as the only actively compiled contest file.
- Files in `snippets/` are reference material only.
- Non-template snippets should document their main preconditions, postconditions, and typical complexity when that meaningfully clarifies usage.

Current topics:

- `template.md`: contest I/O template
- `number-theory.md`: modular exponentiation, extended gcd, modular arithmetic, combinatorics, sieve, primality, factorization
- `union-find.md`: union-find and rollback union-find
- `range-data-structures.md`: Fenwick tree, segment tree, lazy segment tree
- `sparse-table.md`: static idempotent range queries
- `matrix.md`: abstract dense matrix, fast exponentiation, cache-optimized multiplication
- `floor-sum.md`: floor sums and like-Euclidean algorithms
- `inversions.md`: inversion counting with merge sort
- `treap.md`: implicit treap (array representation, range queries, lazy updates, range reversals) and explicit treap (ordered set/multiset BST)
